# NotaFlux

Fluxo aleatório e elegante de notas e acordes para prática musical.

## O que é

NotaFlux é uma ferramenta web simples e sofisticada para treinar reconhecimento de notas e acordes. Você seleciona as notas/acordes desejados, define o intervalo de tempo e o app alterna entre eles de forma aleatória — ideal para ear training, aquecimento ou estudo de progressões.

## Recursos

- **Modo Notas** — selecione notas individuais (mínimo 2)
- **Modo Acordes** — escolha a qualidade (Maior, Menor, 7, m7, maj7, dim, aug, sus4) e combine com as notas
- **Modo Produtor** — monte uma sequência completa (ilimitada, com repetições), edite manualmente e baixe como `.txt`
- **Modo Metrônomo** — metrônomo funcional que vai de 20 a 300 BPMs
- Tempo de troca aleatório (mínimo 2 segundos, configurável)
- Desfazer / Refazer
- Modo apagar (lixeira) e limpar tudo
- Visual luxuoso em tons dourados
- 100% local — funciona offline após abrir o arquivo

## Como usar

1. Escolha o modo (Notas, Acordes ou Produtor)
2. Selecione as notas/acordes desejados
3. Ajuste o intervalo mínimo e máximo de tempo
4. Clique em **Iniciar Fluxo**
5. Pratique até clicar em **Parar**

### Atalhos da interface

| Botão | Função |
|-------|--------|
| ↶ | Desfazer |
| ↷ | Refazer |
| 🗑 | Ativar modo apagar (clique nas notas para remover) |
| ✕ | Limpar toda a seleção |

## Modo Produtor

- Clique nas notas para ir montando a sequência
- Edite o texto livremente no campo
- Use **Aplicar texto** para sincronizar
- **Baixar .txt** salva a melodia para uso posterior

## Requisitos

- Qualquer navegador moderno (Chrome, Firefox, Safari, Edge)
- Não precisa de instalação nem internet após abrir o arquivo
